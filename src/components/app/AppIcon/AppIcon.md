# AppIcon

```tsx
<AppIcon name="check" decorative={false} label="تأیید" />
```

Pass a typed name from the Lucide registry in AppIcon.tsx. Approved names are arrow-left, arrow-right, check, chevron-down, chevron-left, chevron-right, menu, plus, search, and x. The icon inherits its text color and defaults to decorative and medium. A meaningful standalone icon requires decorative false and a label. Decorative icons stay out of the accessibility tree and the tab order. Directional names describe the displayed arrow. Choose the direction appropriate to the action in RTL or LTR.
